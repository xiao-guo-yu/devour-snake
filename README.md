# 吞噬之蛇 · DEVOUR

一个用 Three.js 写的俯视角贪吃蛇 Roguelike 原型：吃掉一切，长得更长，用身体当子弹。

## 在线游玩

部署到 GitHub Pages 后，访问：

`https://<你的用户名>.github.io/<仓库名>/`

## 玩法

- **移动**：WASD / 方向键（8 方向）
- **射击**：空格（消耗 1 节体长）
- **能量球**：E（消耗 3 节，体长需 > 4；命中后 3×3 格清场）
- **视角**：F 切换全图 / 跟随
- **暂停**：P（暂停时显示操作提示）
- **重开**：R

体长就是血量：受伤从尾部断节，体长 ≤ 1 时死亡。

## 流程

1. 从场外小房间出发，爬进温室；
2. 温室 3 小关（孢子怪 → 藤鞭 → 食蝇草）；
3. Boss **腐根盘蛇 · Rootcoil**（140 血，环形弹幕）→ 掉落 3 张技能卡，撞上去获得；
4. 神庙 3 小关（圣甲虫 → 木乃伊 → 阿努比斯）；
5. Boss **黄金法老 · Pharaoh**（380 血，三面扇形弹幕）；
6. 通关。

## 技术

- 纯静态：`index.html` + `game.js` + `start.js` + `vendor/three.min.js`
- 无构建、无后端、无联网依赖，双击 `index.html` 也能玩
- 美术全部是 Canvas 2D 程序化绘制

## 本地运行

直接用浏览器打开 `index.html`，或：

```bash
python -m http.server 8123
```

然后访问 `http://127.0.0.1:8123/`。
