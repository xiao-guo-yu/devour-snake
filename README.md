# 吞噬之蛇 · DEVOUR

一个用 Three.js 写的俯视角贪吃蛇 Roguelike 原型：吃掉一切，长得更长，用身体当子弹。

## 在线游玩

部署到 GitHub Pages 后，访问：

`https://<你的用户名>.github.io/<仓库名>/`

## 玩法

- **移动**：WASD / 方向键（8 方向）
- **射击**：空格（消耗 1 节体长）
- **E 技能**：绿色核心为消耗 3 节、命中后覆盖 3×3 范围的大能量波；红色核心为消耗 2 节、伤害 2 的 2×2 烈焰弹
- **蓝色 E 技能**：寒冰吐息，消耗 2 节，冻结前方大片扇形范围内的敌人
- **Q 技能**：金色核心护盾，消耗 1 节，持续 2 秒，冷却 5 秒
- **视角**：F 切换全图 / 跟随
- **暂停**：P（暂停时显示操作提示）
- **重开**：R

死亡后点击“重新开始”或按 `R` 会从当前关卡重新开始，不会跳回第一关。

体长就是血量：受伤从尾部断节，体长 ≤ 1 时死亡。

藤蔓敌人接触蛇身时会造成伤害，并使移动速度降低 3 秒；该机制适用于所有出现藤蔓的关卡。

## 流程

1. 从场外小房间出发，爬进温室；
2. 温室、神庙、火山、永冻冰原各 7 小关；
3. 每个区域以 Boss 战结束：腐根盘蛇、黄金法老、熔岩巨像、凛冬冰龙；
4. Boss 倒下后吞噬场地中央的 2×2 发光核心，解锁对应技能但不增加体长；
5. 设置 → 技能中可以查看已解锁能力并替换 E 槽，通关传送门会保留技能进度。

永冻冰原每 15 秒会追加一格随机冰障；普通子弹会被挡下，赤核烈焰弹可以将其击碎。

腐根盘蛇每 15 秒会发红眼召唤 2 只随机温室小怪。黄金法老拥有 3 层金色护盾，空格子弹每发消耗 1 层，大能量波可一次击破；护盾破裂 20 秒后重新生成。

## 技术

- 纯静态：`index.html` + `game.js` + `skills.js` + `start.js` + `vendor/three.min.js`
- 无构建、无后端、无联网依赖，双击 `index.html` 也能玩
- 美术全部是 Canvas 2D 程序化绘制

## 本地运行

直接用浏览器打开 `index.html`，或：

```bash
python -m http.server 8123
```

然后访问 `http://127.0.0.1:8123/`。
