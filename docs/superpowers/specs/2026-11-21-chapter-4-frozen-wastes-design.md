# 第四章：永冻冰原 · 关卡主体设计

## 目标

在现有一区 7 关加一区 Boss 的结构上增加第四章“永冻冰原”。本次先完成关卡主体、敌人分布、冰障规则和冰龙龙息；三只小怪的专属机制与最终数值留给后续迭代。

## 战役结构

| 关卡 | 名称 | 敌人构成 |
| --- | --- | --- |
| 4-1 | 霜原边缘 | 冰晶蛞蝓 ×8 |
| 4-2 | 裂冰走廊 | 冰晶蛞蝓 ×5、霜骨狼 ×3 |
| 4-3 | 狼嚎冻谷 | 霜骨狼 ×8 |
| 4-4 | 寒晶蛞蝓穴 | 冰晶蛞蝓 ×5、冰雾灵 ×3 |
| 4-5 | 雾灵回廊 | 冰晶蛞蝓 ×3、霜骨狼 ×2、冰雾灵 ×3 |
| 4-6 | 霜骨荒径 | 霜骨狼 ×5、冰雾灵 ×3 |
| 4-7 | 冰封王座前庭 | 冰雾灵 ×8 |
| 4-8 | 凛冬冰龙 | Boss 战 |

每关清空敌人后开启传送门；Boss 倒下后掉落蓝色核心，吞噬后可解锁“寒冰吐息”，再进入通关传送门。

## 冰晶障碍

- 第四章不继承前三章的固定 2×2 障碍。
- 每 15 秒在可用场地随机生成一个单格冰晶，避开蛇身、传送门、敌人、豆子、Boss 与既有冰晶。
- 普通子弹会被冰晶挡下；赤核烈焰弹命中时击碎冰晶并产生命中爆点。
- 冰晶只在第四章生成，离开第四章后全部清除。

## 凛冬冰龙

- 待机使用冰龙坐姿图；龙息预警和释放阶段切换为张口喷吐图。
- 每轮先锁定蛇头方向并显示扇形预警，再释放覆盖前方大范围扇形的龙息。
- 龙息命中蛇身时按现有弹幕伤害流程结算；“金核壁垒”可以挡住一次龙息命中。
- 本轮先确定攻击形态与碰撞范围，Boss 血量、伤害和节奏数值可在后续平衡阶段调整。

## 暂定占位

冰晶蛞蝓、霜骨狼、冰雾灵目前复用基础追逐和接触伤害框架，不提前添加专属技能。它们的专属机制与最终数值由后续需求补齐。

为便于直接试玩，本轮使用的临时参数如下：

| 项目 | 临时参数 |
| --- | --- |
| 冰障生成间隔 | 15 秒 |
| 龙息预警 / 释放 | 0.85 秒 / 1.15 秒 |
| 龙息扇形 | 约 104°，最远 19 格 |
| 龙息伤害 | 2 格身体，每次龙息最多命中一次 |
| 冰龙生命 | 440（待平衡） |
| 寒冰吐息消耗 / 冷却 | 2 格身体 / 6 秒 |
| 寒冰吐息冻结 | 前方约 122°，13 格内 3 秒 |
