# 前三章关卡地图背景

## 目标

为腐殖温室、黄沙神庙和熔火地脉补齐与后四章一致的全幅关卡地图背景。现有八节点路径、关卡图标、进度和交互保持不变。

## 方案

- 为三个区域各生成一张 1000×1000 的正方形环境背景，无角色、无文字、无 UI。
- 背景只负责地形和氛围，节点区域使用较暗的中央净空与柔和光晕，保证图标和路线可读。
- 腐殖温室采用湿润青绿砖石、树根、藤蔓和苔藓。
- 黄沙神庙采用沙岩地砖、残破石柱、金色壁画光纹和沙尘。
- 熔火地脉采用黑曜石地砖、岩浆裂隙、余烬与火山烟尘。
- 沿用后四章 CSS 结构，在区域地图和关卡地图中叠加现有颜色渐变，不改变 DOM 和交互。
- 新增背景图存放在 `assets/`，同步更新资产来源说明与缓存版本。

## 验收

- 三个区域均显示独立背景，不再是纯色渐变。
- 桌面和手机布局下标题、节点、标签、路线和底部说明清晰可读。
- 后四章及第七章现有背景不受影响。
- 线上构建无脚本错误，图片请求全部成功。
