# 2026-11-21 Boss 核心技能设计

## 目标

将击败 Boss 后的三选一技能卡改为单个可吞噬核心，并让技能成为可持久保存、可在设置中查看和替换的战役能力。

## 规则

- 枯树、法老、魔像分别掉落绿色、黄色、红色核心。
- 核心为直径 2 格的圆球，蛇头接触核心后吞噬；不增加体长，随后开放通关传送门。
- 绿色核心解锁 `E` 大能量波，消耗 3 格身体，命中后覆盖 3×3 范围。
- 红色核心解锁 `E` 烈焰弹。装备红色时替换绿色 `E`；每次消耗 2 格身体，敌人伤害为 2，命中产生 2x2 范围伤害，Boss 伤害为普通射击的两倍。
- 黄色核心解锁 `Q` 护盾。消耗 1 格身体，持续 2 秒，冷却 5 秒；免疫子弹和敌人撞击，不免疫地面岩浆与 Boss 踩踏。
- 绿色和红色共用 `E` 槽，黄色使用独立的 `Q` 槽。可以在设置中替换 `E` 槽，三个技能的能力状态彼此保留。
- 新获得的核心会自动装备；解锁与装备状态保存在浏览器本地。
- 设置增加“音频 / 技能”页签。技能页显示解锁状态、按键、效果和安装状态。
- 游戏中按 `P` 暂停后，暂停面板提供“技能设置”入口并直接打开技能页。
- 游戏 HUD 显示已装备技能、`Q` 护盾持续时间与冷却。

## 实现边界

- 保留现有 Three.js、原生 DOM/CSS 和静态站点结构，不引入框架或构建步骤。
- 删除原有 `E` 能量波及其三张卡牌逻辑。
- 沿用现有协议式绿金视觉，不重做整体界面。
